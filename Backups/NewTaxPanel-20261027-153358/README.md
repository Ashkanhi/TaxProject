# نسخهٔ قبلی پنل NewTax

این نسخه در ۲۰۲۶/۱۰/۲۷، قبل از بازطراحی چیدمان پنل ارسال و استعلام، ذخیره شد.
سه فایل داخل این پوشه نسخهٔ کامل پیش از تغییر هستند؛ مسیر اصلی آن‌ها در `files.txt` ثبت شده است.

برای بازگشت، اسکریپت `Restore.ps1` همین پوشه را در PowerShell اجرا کنید و برنامه را دوباره Build کنید.
اسکریپت فقط همین سه فایل ظاهر پنل NewTax را برمی‌گرداند و فایل‌های Tax و Omid را تغییر نمی‌دهد.
بازگردانی، ویرایش‌های بعدی این سه فایل را جایگزین خواهد کرد.
